# Проект “Табло теннисного матча”
[Веб-приложение](http://91.245.227.11:8080/crudProject/), реализующее табло счёта теннисного матча.

## Используемые технологии

### Java
- Коллекции
- Объектно-ориентированное программирование (ООП)
### Паттерн проектирования
- MVC(S)
### Инструменты сборки
- Maven
### Backend
- Java Servlets, JSP
- HTTP (GET и POST запросы, формы)
### Базы данных
- SQL
- Hibernate (ORM)
### Frontend
- HTML/CSS
- Блочная вёрстка
### Тестирование
- Юнит-тестирование с использованием JUnit 5
### Деплой
- Облачный хостинг
- Работа с командной строкой Linux
- Tomcat


## Мотивация проекта

- Создание клиент-серверного приложения с веб-интерфейсом.
- Получение практического опыта работы с ORM Hibernate.
- Разработка простого веб-интерфейса без использования сторонних библиотек.
- Ознакомление с архитектурным паттерном MVC(S).

## Функционал приложения

### Работа с матчами

- Создание нового матча.
- Просмотр списка завершённых матчей и поиск по именам игроков.
- Подсчёт очков в текущем матче.
